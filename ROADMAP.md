# XHL development roadmap

All items are **planned**, not implemented or verified.

## 0. Import and baseline
- [ ] Import and inspect the existing v1.0.1 reliability patch
- [ ] Separate source code, build outputs, assets and runtime data
- [ ] Identify dependencies and confirm a reproducible build
- [ ] Audit the source and package for secrets and private data

## 1. Reliable launcher
- [ ] Steam/game prerequisite validation
- [ ] Existing installation discovery and in-place migration preview
- [ ] Confirmations, recovery strategy and human-readable folders
- [ ] Launcher icon, shortcut and animated informative splash screen
- [ ] Troubleshooting and logging

## 2. Server activity
- [ ] Live event console and filtering
- [ ] Player connection and activity display
- [ ] Location/town names when supported by accessible game data

## 3. Character and save management
- [ ] Detailed character page
- [ ] Inventory inspection and controlled item changes
- [ ] Save discovery, backup, validation and restore
- [ ] Version compatibility and corruption prevention

## 4. Distribution
- [ ] Automated build/test workflow after identifying the toolchain
- [ ] Tagged releases with downloadable packages and changelogs
