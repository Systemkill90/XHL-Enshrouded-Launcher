# What ShroudForge can do

A quick, nontechnical overview. Features described below are present in the **development source** or reported on the owner's existing host—not necessarily in a public release.

| Feature | What it means for players and hosts |
| :-- | :-- |
| **Server control** | Start, stop or restart a dedicated server through a normal desktop interface |
| **Status dashboard** | See server uptime, observed activity, players and system-resource use |
| **Save protection** | Take and inspect backups; stage safer restore operations |
| **Gameplay mods** | Keep approved, build-specific flight, gifting and stacking modifications organized |
| **Game updates** | Prepare a version separately and check compatibility before switching |
| **Player history** | Examine observed sessions and activity without claiming data the server doesn't provide |
| **Private phone access** | View/control select functions from a trusted local network |

## What is still experimental?

More detailed character inventories, exact player positions, custom vanilla-client quest tracking and an in-game minimap **have not been established as supported server-only features**. They are not promised for a public release.

### What about a new Enshrouded update?

Mods based on game data or runtime patches may break when a new build arrives. Compatibility has to be established for the **exact build**, and we will not silently update a working public server.
