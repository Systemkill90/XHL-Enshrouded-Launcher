# Getting started with ShroudForge

ShroudForge is a Windows desktop control room for an **Enshrouded dedicated server**. It's intended to give hosts a clear picture of their world, help protect saves and make routine server management less frustrating.

## Can I download it?

**Not as a public supported installer today.** The project owner's public Velaris server has a working setup, but newer features are still being reviewed in development branches.

When an approved release exists, get it from [GitHub Releases](https://github.com/Systemkill90/XHL-Enshrouded-Launcher/releases). Avoid third-party downloads claiming to be official.

## What will I need?

- A Windows host that can run the official Enshrouded dedicated server.
- Your own game server from Steam Tools or SteamCMD. **ShroudForge does not bundle the game.**
- A reliable location for world/configuration backups, ideally on a different drive.
- A ShroudForge package specifically marked compatible with your installed Enshrouded version.

## Already running a server?

Keep the current launcher, server files and saves. **Don't replace a working installation just because you see a newer commit.** The installer/workflow will be documented with its corresponding supported release.
