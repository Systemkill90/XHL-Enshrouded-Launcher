# Getting started

Welcome! **Enshrouded Server Companion** is meant to take the hassle out of hosting your own Enshrouded dedicated server on a Windows PC.

## Can I install it today?

**Not from this repository yet.** The project owner has reported a working local build, and 2.0 code is being reviewed, but a public install package has not been published. The [Releases page](https://github.com/Systemkill90/XHL-Enshrouded-Launcher/releases) is the place to check for an official package when one exists.

If you already have the working private build, **keep it**. Do not replace your current server or overwrite saves merely because a newer code branch appears on GitHub.

## What will I need?

- A Windows PC that can run the official Enshrouded dedicated server.
- A legal installation of the official dedicated server, supplied through Steam's Tools section or SteamCMD.
- A separate place for save backups. A second drive is better than a folder inside the game-server installation.
- The official companion package **once a version has been published**.

The manager is not a replacement for the game server itself.

## What setup will look like when the public installer is ready

1. Download a tested package from this repository's **Releases** page.
2. Open the program and point it to your existing Enshrouded server folder, or choose a guided new setup if the released version supports it.
3. Review the detected settings and backup location *before* making changes.
4. Start the server from the app and confirm it is online.
5. Enable optional features such as backups or compatible mods only after the basic server works.

These are the **planned user steps**, not a claim that the downloadable release already exists. The exact screens and requirements will be documented with that release.

## Already running a server?

Don't move files, reinstall Enshrouded, or delete your current startup method yet. The project is being developed with existing hosts in mind. Make a copy of your world and configuration before trying a new version.

For the current development status, see [What works and what is next](STATUS.md). For feature explanations, see [Features](FEATURES.md).

## Need help or want a feature?

Use [GitHub Issues](https://github.com/Systemkill90/XHL-Enshrouded-Launcher/issues) and describe what you tried, what happened, and what you expected. You do **not** need to understand the code to report a problem. Remove passwords and private server information before posting.
